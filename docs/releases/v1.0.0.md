# ResumeForge v1.0.0 — Stable Release Notes

ResumeForge is an open-source, self-hosted resume creation application for individuals who want structured editing, readable resume exports and transparent job-description matching.

## Included Capabilities

- Resume dashboard with create, open, rename, duplicate, delete and validated JSON backup/import.
- Structured resume editing, live preview, local draft recovery and version-history restore.
- Four selectable single-column layouts: Modern, Classic, Minimal and Executive.
- Downloadable PDF and DOCX documents with A4 or US Letter page selection.
- Deterministic 0–100 **Resume Quality Score** with documented category weights and improvement suggestions.
- Job-description matching against resume evidence and relevant keywords.
- Private browser-held ownership capability and revision-checked updates that reject stale writes.
- Single-instance Docker Compose deployment, optional Kubernetes manifests with durable SQLite storage, and an operations/backup guide.

## Scope And Privacy

v1.0.0 is designed for **self-hosted, browser-based personal resume management**, not a managed multi-tenant SaaS. Browser capability keys are not user accounts. Anyone who obtains a key can access the associated private resumes. Use HTTPS and keep browser storage and JSON backups secure. Losing a key can prevent access to its stored resumes. There is no cross-device account synchronization.

The application does not promise that any employer's ATS will accept or rank a resume. Quality scores and job matching are advisory, rule-based outputs. Existing DOCX/PDF documents are exported; importing already-written resumes is not currently supported beyond validated JSON backups.

## Verification Requirements

The stable tag is created only after the release workflow passes:

- Schema, frontend and API tests.
- CodeQL, secret scanning and dependency audits.
- Kubernetes manifest rendering.
- API and web container builds with Trivy vulnerability scans.
- Browser acceptance checks across resume editing, exports, analysis and privacy isolation.
- SPDX SBOM generation and keyless signing of the exact scanned GHCR image digests.

GitHub Releases includes the SPDX SBOM files and immutable image digest evidence. Check the release workflow logs for the signing identity and certificate transparency details.
