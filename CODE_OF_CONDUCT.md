Code of Conduct
Our Pledge
We are committed to making participation in the ResumeForge project a welcoming, respectful, and inclusive experience for everyone.
We expect all contributors, maintainers, reviewers, and community participants to interact professionally and respectfully.
Expected Behavior
Examples of behavior that contribute to a positive environment include:
Being respectful and considerate of others.
Giving and accepting constructive feedback.
Focusing on the technical issue rather than the individual.
Respecting different viewpoints, backgrounds, and experiences.
Using welcoming and inclusive language.
Taking responsibility for mistakes and working constructively to resolve them.
Keeping discussions relevant to the project.
Respecting project maintainers, reviewers, and other contributors.
Unacceptable Behavior
The following behavior is not acceptable:
Harassment, discrimination, or intimidation.
Personal attacks or insults.
Trolling or deliberately disruptive behavior.
Publishing private or sensitive information about another person without permission.
Sexualized language or unwanted sexual attention.
Threats of violence or other threatening behavior.
Deliberate disruption of project discussions, reviews, or development workflows.
Any other conduct that would reasonably be considered inappropriate in a professional open-source community.
Enforcement Responsibilities
Project maintainers are responsible for clarifying and enforcing the standards described in this Code of Conduct.
Maintainers may take appropriate and proportionate action in response to behavior that violates this Code of Conduct.
Possible actions may include:
Asking a participant to stop inappropriate behavior.
Removing or editing inappropriate comments.
Closing discussions or issues.
Restricting participation in project discussions.
Removing a contributor from project spaces where necessary.
Reporting
If you experience or witness unacceptable behavior, report it privately through the project's designated security or communication channels.
For security vulnerabilities, please follow the process described in `SECURITY.md`.
Do not use public GitHub issues to report sensitive security matters.
When reporting a conduct issue, provide enough information for maintainers to understand what happened and, where possible, include relevant links or context.
Reports will be handled as confidentially as reasonably possible.
Scope
This Code of Conduct applies to project spaces and interactions related to ResumeForge, including:
GitHub issues
Pull requests
Code reviews
Discussions
Project documentation
Other project-maintained communication channels
It also applies when an individual is officially representing the project in public spaces.
Enforcement
Maintainers will make reasonable efforts to review reported incidents and determine appropriate action based on the circumstances.
Enforcement decisions should be made consistently, proportionately, and with the goal of maintaining a respectful project environment.
